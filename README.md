# Aaron Fanxi Su — personal website

Live site: https://arsuepic.github.io/

A responsive, graffiti-inspired portfolio with cyan, pink, yellow, original SVG illustrations, selected projects, award filters, and contact links.

## Edit the site

Everything is in `index.html`: page content, styles, illustrations, and JavaScript. No package installation or build step is required.

Edit `index.html` in GitHub and commit to `main`. GitHub Pages publishes the repository root.

## Preview locally

Open `index.html` in your browser, or run the following command in this folder:

```sh
python3 -m http.server 8765
```

Then visit http://localhost:8765. The email-copy button requires HTTPS or localhost; the email link also works without it.

## Content

Biographical information and achievements were supplied by Aaron. Wikipedia statistics are dated November 2026. The original résumé, phone number, grades, test preparation details, and precise location are not published.

The page includes reduced-motion support, visible keyboard focus, an accessible mobile menu, and live status messages for award filtering and email copying.
